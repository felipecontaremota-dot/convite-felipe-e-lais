# Felipe & Laís — nossa próxima aventura

Cena piloto de 15 segundos para o convite de casamento. HTML, CSS e JavaScript, sem dependências de produção ou serviços pagos.

## Executar

Na pasta do projeto: `python -m http.server 8000`. Abrir http://localhost:8000.

## Conteúdo

- Personagens baseados no estudo visual aprovado, em duas pranchas PNG com transparência.
- Cenário vetorial original, quatro balões e encerramento.
- Início por toque, pausa, repetição, transcrição e controle de som. Áudio desligado inicialmente, sintetizado no navegador com uma melodia simples original.
- Pausa automática ao ocultar a página e redução de movimentos conforme preferência do dispositivo.

## Publicação

Para publicar pelo GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root). Este repositório ainda não configura publicação automática por workflow.

## Estado da versão

Piloto visual, sem data/local/RSVP. Os diálogos são uma proposta ficcional para a aventura, não uma reconstituição do encontro real. As pranchas ainda precisam de quadros complementares para uma caminhada fluida; esta versão usa deslocamento e balanço simples. Fotografias originais e lista de convidados não integram o repositório.
